# 《灵山大掌门》v0.12.1 验收说明

状态：开发完成，等待用户验收。

## 本版范围

1. NPC朝向、排队状态和提前离场路径修复。
2. 宗门大殿完整碰撞与西侧庭院绕行。
3. 旧存档临时访客和商铺队列安全清场。
4. 桌面与手机横屏默认显示地图四角，保留缩放和拖动。
5. 旧丹药链与新炼器链建筑分别校准体量、脚点、入口、点击和碰撞。

未包含：灵器研发/长老、经济调价、随机事件、练功房人数上限、装饰建造入口、灵田/炼丹房/丹药铺特效。以上留待v0.12.2另行确认。

## 用户验收步骤

1. 读取一份旧存档：预期旧访客不残留在丹药铺/法器铺边缘，资源、建筑和永久统计保留。
2. 在北部和中部各建一座商铺并补货：预期访客绕过宗门大殿，不穿底部；往返朝向与移动一致。
3. 观察默认镜头：预期地图四角可见；滚轮或触摸缩放、拖动后可继续查看局部，缩回后恢复完整地图。
4. 将八类建筑放在同一区域：预期新旧建筑体量接近，脚点、点击区、标签和入口无明显错位。
5. 跑一次灵田→炼丹房→丹药铺，以及灵矿场→炼器坊→法器铺：预期两条链均正常经营和保存。
